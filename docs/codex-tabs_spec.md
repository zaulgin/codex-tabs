# Codex Tabs — спецификация

Version: 1

Outcome: отдельное VS Code расширение-дополнение к установленному `openai.chatgpt`, позволяющее открыть несколько официальных чатов во вкладках и выбрать существующий разговор из общей локальной истории.

User value: параллельная работа с Codex без повторной реализации официального интерфейса.

Scope:
- Новая сессия открывает официальный `chatgpt.conversationEditor` с уникальным URI.
- Общая история CLI/IDE в том же окружении Codex: поиск и постраничная загрузка через App Server, открытие выбранного ID официальным редактором.
- Повторное открытие уже открытого разговора фокусирует его вкладку.
- Официальные очередь, steering, разрешения, IDE-контекст, ссылки на файлы и вставка изображений продолжают обслуживаться официальным клиентом.
- Целевой ручной сценарий: Windows VS Code → Remote SSH → Linux, включая вставку изображения из буфера Windows.
- Устанавливаемый VSIX, исходники, автоматические проверки и инструкция ручной проверки.

Non-goals: копирование/правка официального bundle, новый чат UI, собственное выполнение модельных запросов, чтение JSONL переписок или credentials напрямую, публикация/установка/commit/push без отдельного запроса.

Constraints:
- Внутренняя схема `openai-codex://route/` не является стабильным публичным API. Проверенный статически официальный пакет: `26.1111.21308`.
- Уникальный URI доказывает идентичность редактора, но независимость разговора/черновика требует настоящей проверки VS Code.
- История относится к выбранному Codex home и extension host; облачная синхронизация между компьютерами не обещается.
- При открытии истории запускается отдельный краткоживущий App Server; дополнение отправляет только initialize/thread/list. Никаких thread/start/resume/turn или ответов, разрешающих действия. Это ограничение RPC, а не гарантия read-only процесса: сам Codex при старте может инициализировать своё хранилище и выполнять штатные фоновые действия. Дополнение отключает telemetry для своего процесса через аргументы, не меняя config.toml. Данные чатов и stderr не выводятся в логи.
- Запуск CLI разрешён только в доверенном workspace. Путь к CLI задаётся настройкой уровня компьютера; shell не используется.
- Содержимое истории не считается командами; допустимость идентификатора проверяется до построения URI.

Acceptance criteria:
1. Команда создаёт разные URI новых редакторов; открытие истории использует стабильный URI разговора.
2. История поддерживает пагинацию и поиск; пустые/ошибочные данные дают понятное состояние без утечки содержимого ошибок сервера.
3. RPC корректно завершает процессы при завершении, отмене, таймауте и ошибке; серверные запросы действий отвергаются.
4. Сборка VSIX содержит только необходимые файлы дополнения и не включает официальный код, тесты, планы, секреты и локальные артефакты.
5. Перед заявлением о полном сохранении поведения вручную проверены независимые чаты, очередь/steering, история, ссылки и Windows→SSH paste. Без этого результат — прототип с явно указанными пробелами.

Open questions: фактическая независимость состояния официальных вкладок и remote paste выясняются прототипом; это не считается уже подтверждённым.

Acceptance source: обсуждение в этой сессии — N вкладок, общая история, максимальное сохранение официальных функций, локальная Windows; пользователь предоставил `/root/github/codex-tabs` для реализации выбранного дополнения.
